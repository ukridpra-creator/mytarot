ไบโอริธึม
กราฟชีวิต 3 วงจร

ทฤษฎีวงจรคลื่นของร่างกาย อารมณ์ และสมอง ที่นับจากวันเกิดค่ะ

✦ ไบโอริธึมคืออะไร

ไบโอริธึม (Biorhythm) เป็นทฤษฎีที่ว่ามนุษย์มีวงจรพลังงาน 3 ด้านเริ่มนับตั้งแต่วันเกิด และแต่ละวงจรขึ้นลงเป็นคลื่นไซน์ซ้ำไปเรื่อยๆ ตลอดชีวิตค่ะ

ทฤษฎีนี้ได้รับความนิยมในช่วงปี 1970 และยังเป็นที่รู้จักในฐานะ "กราฟชีวิต" จนถึงทุกวันนี้

ความจริงที่ควรรู้: งานวิจัยทางวิทยาศาสตร์ไม่พบหลักฐานว่าไบโอริธึมทำนายสมรรถภาพหรืออารมณ์ได้จริง ที่นี่นำเสนอเป็นเครื่องมือสนุกๆ สำหรับวางแผนและสะท้อนตนเอง ไม่ควรใช้ตัดสินเรื่องสำคัญค่ะ

✦ 3 วงจรหลัก

แต่ละวงจรมีความยาวคงที่ นับจากวันเกิดเป็นวันที่ 0 ค่ะ

วงจรความยาวเกี่ยวกับ
ร่างกาย23 วันแรง ความทนทาน การประสานงานของร่างกาย
อารมณ์28 วันความรู้สึก ความไวต่ออารมณ์ ความสัมพันธ์
สติปัญญา33 วันการคิด ความจำ การตัดสินใจ

✦ อ่านกราฟอย่างไร

  • ช่วงบวก เส้นอยู่เหนือศูนย์ แปลว่าวงจรนั้นอยู่ในช่วงขาขึ้น
  • ช่วงลบ เส้นอยู่ใต้ศูนย์ แปลว่าอยู่ในช่วงพักตัวหรือขาลง
  • วันวิกฤต วันที่เส้นตัดผ่านศูนย์ ถือว่าเปลี่ยนผ่านและควรระวังเป็นพิเศษ
  • เส้นสูงทั้ง 3 ถือเป็นช่วงที่น่าลงมือทำเรื่องสำคัญ ส่วนช่วงที่ต่ำทั้ง 3 ควรพักและวางแผนช้าๆ

✦ วิธีคำนวณแบบง่าย

หาจำนวนวันตั้งแต่วันเกิดถึงวันนี้ นำไปหารด้วย 23, 28 และ 33 แล้วดูเศษที่เหลือ เศษนั้นบอกว่าอยู่ตำแหน่งไหนของคลื่นในวงจร ค่าไซน์ของตำแหน่งนั้นคือค่าที่ปรากฏบนกราฟค่ะ

วงจรทั้ง 3 จะกลับมาเริ่มพร้อมกันอีกครั้งทุก 21,252 วัน (ประมาณ 58 ปี) ตามหลักคณิตศาสตร์ของตัวคูณร่วมน้อย

✦ ใช้ไบโอริธึมอย่างสร้างสรรค์

  • ใช้เป็นข้ออ้างให้ตัวเองหยุดพักเมื่อรู้ตัวว่าเหนื่อย
  • ใช้จดบันทึกอารมณ์ประจำวันเทียบกับกราฟ เพื่อดูว่ามีรูปแบบจริงหรือไม่
  • ไม่ควรใช้กำหนดว่าจะไปผ่าตัด สอบ หรือขับรถ เพราะไม่มีหลักฐานรองรับ
ดูกราฟไบโอริธึมของคุณ
ใส่วันเกิด ระบบวาดกราฟ 3 วงจรให้เห็นว่าวันนี้อยู่ขาขึ้นหรือขาลงค่ะ

ไบโอริธึม Biorhythm กราฟชีวิต 3 วงจร 23 28 33 วัน และข้อจำกัดทางวิทยาศาสตร์

ไบโอริธึมคือทฤษฎีวงจรชีวิต 3 ด้าน ได้แก่ ร่างกาย 23 วัน อารมณ์ 28 วัน สติปัญญา 33 วัน คำนวณจากวันเกิดแล้วแสดงเป็นกราฟไซน์ ใช้วางแผนกิจกรรมอย่างสนุกๆ แม้ไม่มีหลักฐานทางวิทยาศาสตร์รองรับค่ะ

ไบโอริธึมคืออะไร

เป็นทฤษฎีวงจร 3 ด้าน คือร่างกาย 23 วัน อารมณ์ 28 วัน และสติปัญญา 33 วัน นับจากวันเกิดค่ะ

ไบโอริธึมแม่นไหม

งานวิจัยไม่พบหลักฐานว่าทำนายได้จริงค่ะ ควรใช้เป็นเครื่องมือสะท้อนตนเองเท่านั้น
