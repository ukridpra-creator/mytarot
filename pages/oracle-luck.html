The Fortune Code คืออะไร?

The Fortune Code คือไพ่ออราเคิลสำรับพิเศษ 30 ใบที่ออกแบบมาเพื่อวัดพลังงานด้านเงินทองและโชคลาภโดยเฉพาะค่ะ แบ่งเป็น 3 กลุ่มพลัง ได้แก่ The Takers (พลังแห่งการสูญเสีย) The Weavers (พลังแห่งจังหวะและการเปลี่ยนแปลง) และ The Givers (พลังแห่งความมั่งคั่ง) ที่ My Tarot คุณพี่สามารถเลือกไพ่ 3 ใบเพื่อดูพลังหลัก พลังสนับสนุนหรือแรงต้าน และผลลัพธ์ พร้อมคำนวณเปอร์เซ็นต์พลังโชคลาภโดยรวมและคำทำนายตามระดับพลังงานได้ฟรีค่ะ
