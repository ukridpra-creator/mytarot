Love Code คืออะไร?

Love Code คือการวิเคราะห์ความเข้ากันของคู่รักด้วยหลักเลขศาสตร์ค่ะ นำวันเดือนปีเกิดของคุณพี่ทั้งสองคนมาคำนวณ เพื่อเปิดเผยดวงสมพงษ์ พลังงานความสัมพันธ์ จุดที่เข้ากันได้ดี และจุดที่ควรระวังในความรัก ช่วยให้คุณพี่เข้าใจกันและกันมากขึ้นค่ะ

Love Code ดูอะไรบ้าง?

ระบบจะคำนวณเลขเส้นทางชีวิตของทั้งสองฝ่ายจากวันเกิด แล้ววิเคราะห์ว่าพลังงานสองเลขนี้ส่งเสริมหรือปะทะกันอย่างไรค่ะ ครอบคลุมทั้งเรื่องการสื่อสารในความสัมพันธ์ จังหวะชีวิตที่ต่างกัน จุดที่มักทะเลาะกันซ้ำๆ และวิธีปรับเข้าหากันแบบเป็นรูปธรรม ไม่ใช่แค่บอกว่าเข้ากันได้กี่เปอร์เซ็นต์ค่ะ

เลขไหนเข้ากับเลขไหนได้ดี?

ในเลขศาสตร์ไม่มีคู่ไหนที่ไปด้วยกันไม่ได้เลยค่ะ มีแต่คู่ที่ต้องใช้ความเข้าใจมากกว่าปกติ เช่น เลข 4 กับเลข 5 ที่ฝ่ายหนึ่งต้องการแผนแน่นอนส่วนอีกฝ่ายต้องการอิสระ ถ้าคุณพี่อยากรู้ว่าเลขของตัวเองเข้ากับเลขไหนได้ดี อ่านได้ในบทเรียน เลขชีวิต ซึ่งมีรายละเอียดครบทั้ง 9 เลขค่ะ

ต้องใช้ข้อมูลอะไรบ้าง ใช้กี่เหรียญ?

ใช้แค่วันเดือนปีเกิดของทั้งสองคน ไม่ต้องรู้เวลาเกิดค่ะ ค่าบริการ 10 เหรียญต่อการวิเคราะห์หนึ่งครั้ง ถ้าคุณพี่ยังไม่เคยลองเลขศาสตร์มาก่อน แนะนำให้เริ่มจาก Energy Code ที่ใช้ได้ฟรีก่อน แล้วค่อยมาดู Love Code ต่อค่ะ
